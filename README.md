# 拾课 · 实验台

第二十届全国大学生软件创新大赛，赛题《AI 赋能学习生产力》参赛项目的技术验证页。

作品方向：**「拾课」——以你的课堂笔记为锚，反向校验课堂记录的证据链**。
不替你上课、不替你记，而是告诉你这一节课你**记漏了什么、记错了什么**，每条都能点回到第几秒的原声和那半块黑板。

## 页面

- `index.html` —— 说明页
- `device-test.html` —— 真机采集实验

## 真机采集实验测什么

| 指标 | 判据 | 为什么要测 |
|---|---|---|
| 断流 | 相邻音频分片间隔 > 6.5 秒 | 锁屏/切后台被系统节流会让录音静默中断，而页面上看不出来 |
| 内存 | JS 堆峰值、增长量 | 45 分钟长录音若持续涨内存，会被系统杀掉 |
| 录音忠实度 | 回声消除 / 降噪 / 自动增益的实际取值 | 课堂要环境原声，通话优化会吃掉细节 |
| 体积 | 每秒码率 → 45 分钟估算 | 决定能否长期存在设备本地 |

结果全部在页面本地计算并显示，**不上传任何数据**。录音只留在浏览器内存中，停止后即丢弃。

## 已验证（桌面 Blink 内核）

- 分片录音 → 重组 → 解码可播放：成立
- 时钟漂移：**常量约 250 毫秒**（12 秒与 300 秒测试均为 0.24–0.25 秒），不需要周期重锚
- MediaRecorder 原生 webm **无时长字段**（`<audio>.duration = Infinity`，无法 seek）→ 需 `ffmpeg -c copy` 重封装（体积仅 +0.3%）
- 静态服务必须支持 **HTTP Range / 206**，否则时间轴拖不动
- 45 分钟录音约 8.4–10.6 MB
