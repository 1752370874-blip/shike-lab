真机采集实验 →
在手机上实测：长录音会不会断流、锁屏切后台会不会丢、内存会不会涨爆、浏览器实际采用的录音参数。结果直接显示在页面上，不需要上传。

这个实验回答什么

  • 断流——录音分片 5 秒一片，若某两片间隔超过 6.5 秒，说明被系统节流或挂起
  • 功耗/内存——45 分钟的课，页面内存会不会涨到被系统杀掉
  • 忠实度——回声消除、降噪、自动增益是否真被关掉（课堂要环境原声，不要"通话优化"）
  • 时长——一节课大约 10 MB，能否长期存在本地
怎么测：点「开始录音」→ 录 5 分钟以上 → 中途锁屏 2 分钟 → 解锁回来点「停止并出结果」。
页面会直接给出「未断流 / 被节流 / 明显断流」的判定，不需要另外回传数据。
静态托管在 GitHub Pages，无后端、无上传、不采集任何数据；录音只留在你手机的浏览器内存里，停止后即丢弃。
